# Sana — цифровая грамотность для 1–4 классов

Дипломный учебный проект: React Native / Expo, русский и казахский интерфейс, 69 авторских микроуроков, озвучка темы по кнопке, пять видов интерактивных упражнений. Все уроки открыты сразу. Прогресс отображается количеством завершённых уроков, например 11 / 17.

## Оформление

В настройках доступны светлая и тёмная темы. Выбор сохраняется локально, работает без сети и применяется к урокам, упражнениям и форме аккаунта.

## Быстрый запуск на Windows

Требуется Node.js 24+. В папке `sana`:

```powershell
npm ci
npm run build:web
npm run server
```

Открыть http://127.0.0.1:8787. В собранной веб-версии сервер одновременно раздаёт приложение и API. Регистрация работает сразу, внешняя база данных не нужна. Данные сохраняются в `server/data/sana.db`; папка не включается в Git.

Для просмотра интерфейса во время разработки: `npm run web`. В этом режиме API запускается отдельно (`npm run server`), а в окне входа нужно указать `http://127.0.0.1:8787`. Статический предпросмотр не равен нативному установочному файлу.

## Учебные материалы

| Класс | Уроков |
|---|---:|
| 1 | 10 |
| 2 | 17 |
| 3 | 20 |
| 4 | 22 |

В каждом уроке две короткие страницы объяснения и упражнение. В практических играх есть дополнительный вопрос по содержанию. После неверного ответа показывается объяснение и разрешена повторная попытка. Завершение сохраняется только после успешного выполнения, при повторном прохождении число пройденных уроков не увеличивается.

Упражнения: выбор ответа, последовательность действий, сопоставление пар, построение маршрута робота, композиция из фигур. Компьютерные действия, робот и ИИ адаптированы для тренажёра; это не полноценные редакторы Scratch, презентаций, аудио и не реальный ИИ-сервис.

Авторские объяснения основаны на тематической структуре официального методического руководства НАО им. Ы. Алтынсарина 2026 года. Программа на 2026–2027 год включает основы ИИ. Источники и границы покрытия — `docs/CURRICULUM.md`. Не заявляется полное достижение всех практических целей школьного курса. Педагогическая апробация и независимая редактура казахского текста не проводились.

## Аккаунты и синхронизация

- Один аккаунт соответствует одному ученику. Используются псевдоним, логин и пароль. Почта, дата рождения, школа и адрес не запрашиваются.
- Вход и регистрация требуют доступного сервера. После входа уроки и сохранение прогресса работают без сети, в том числе после перезапуска.
- Результаты синхронизируются после урока, при возвращении в приложение и раз в 30 секунд при открытом приложении.
- Результаты двух устройств объединяются: завершённый урок не становится незавершённым, лучший результат не уменьшается.
- Данные разных аккаунтов и пробного режима разделены. Пробные результаты не переносятся в аккаунт автоматически.
- Нативный токен хранится в SecureStore, учебный прогресс — в AsyncStorage. В браузере данные хранятся в локальном хранилище браузера.
- Пароли хешируются scrypt с индивидуальной солью; на сервере хранится хеш токена, а не токен. Сессия действует 30 дней. Есть ограничение попыток входа и удаление аккаунта с подтверждением пароля.
- Восстановление пароля по почте не реализовано. Для дипломной демонстрации сохраните реквизиты у взрослого.

### Телефон и iPad

Оба устройства должны использовать один адрес сервера. `localhost` на iPhone означает сам iPhone, а не Windows-компьютер.

Для локального браузерного показа в одной доверенной Wi-Fi сети:

```powershell
$env:HOST = '0.0.0.0'
npm run server
```

На устройствах открыть `http://<локальный-IP-компьютера>:8787`. Windows Firewall должен разрешать это подключение. Программа не меняет брандмауэр автоматически. Для офлайн-веб-приложения на телефоне необходим HTTPS: service worker не работает на обычном HTTP-адресе локальной сети. Не используйте реальные пароли в HTTP-демонстрации.

Для постоянного доступа и нативных сборок разверните сервер с HTTPS, затем укажите `EXPO_PUBLIC_API_URL` в `.env` перед сборкой. Используйте собственный домен или HTTPS-туннель для разработки. Интернет нужен для синхронизации, но не для загруженных уроков. Публичный сервер в рамках этой работы не развёрнут.

## Android и iOS

Бесплатный путь для iPhone через GitHub Actions и AltStore на Windows подготовлен в [docs/IOS-FREE.md](docs/IOS-FREE.md). Конфигурация `.github/workflows/ios-unsigned.yml` создаёт неподписанный IPA; облачная сборка успешно выполнена, установка на устройстве пока не проверена.

Проект использует общий React Native интерфейс для телефона и планшета. Веб-версия предоставлена дополнительно для проверки на Windows.

Готовый файл `deliverables/Sana-Android-arm64.apk` можно установить на ARM64-устройство с Android 7.0 или новее. Все 69 уроков и 138 аудиозаписей встроены. Это демонстрационная сборка с debug-подписью; на физическом устройстве она пока не проверена. Для аккаунта и синхронизации укажите HTTPS-адрес своего сервера в расширенных настройках входа. Публичный сервер не включён. Неподписанный IPA для iPhone/iPad собран: `deliverables/ios/Sana-unsigned.ipa`, iOS/iPadOS 16.4+. Его можно подписать бесплатным Apple Account через AltStore на Windows; см. `docs/IOS-FREE.md`. Подробности сборки на Windows находятся в `docs/VALIDATION.md`.

Предпросмотр на iPhone через Expo Go:

```powershell
npm start
```

Нужна совместимая с SDK 58 версия Expo Go и доступ к Metro. Этот режим разработки не является самостоятельной офлайн-установкой. Для проверки офлайн используйте standalone-сборку.

Конфигурация EAS включена в `eas.json`:

```powershell
npx eas-cli login
npx eas-cli build --platform android --profile preview
npx eas-cli build --platform ios --profile preview
```

Android preview создаёт APK. Для iOS нужны аккаунт Apple Developer, подпись и регистрация устройства для internal distribution либо TestFlight через production build. С Windows можно отправить сборку в EAS; локальная сборка iOS требует macOS/Xcode. Оплата и публикация в магазинах не выполнены. `native-dist` — JavaScript и ресурсы платформ, не APK/IPA.

## Озвучка

138 MP3-файлов входят в приложение: по одному на каждый урок и язык. Воспроизведение не обращается к сервису синтеза. Основные голоса: `ru-RU-SvetlanaNeural`, `kk-KZ-AigulNeural`; при сбое русского голоса используются `ru-RU-DmitryNeural` или мультиязычный `en-US-AvaMultilingualNeural`. Для повторной генерации нужны Python 3.12+, `pip install edge-tts` и интернет:

```powershell
npm run audio
```

Генератор отправляет только авторский текст уроков, не пользовательские данные. Кеш по SHA-256 позволяет возобновить генерацию. Перед публичным распространением отдельно проверьте условия использования выбранного провайдера синтеза.

## Проверки

```powershell
npm run typecheck
npm test
npm run build:web
npm run build:native
npx playwright install chromium
# Сервер должен работать в другом терминале:
npm run test:e2e
```

Интеграционные тесты сервера используют отдельную базу в памяти. UI-тесты используют отдельные браузерные профили; не запускать их против пользовательской production-базы. Описание выполненных проверок — `docs/VALIDATION.md`.

## Структура

`App.tsx` — экраны и жизненный цикл; `src/content.ts` — весь двуязычный контент; `src/Games.tsx` — игры; `src/LessonScreen.tsx` — урок и аудио; `src/storage.ts` — локальное хранилище и API; `server/server.mjs` — автономный сервер Node.js/SQLite; `tests` и `e2e` — проверки; `assets/audio` — готовая озвучка.
