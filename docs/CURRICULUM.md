## Учебный сценарий

Объяснение → пример → игровое задание → вопрос по теме (для практических игр) → подтверждение завершения. Ошибка не блокирует ученика: показывается объяснение, разрешена новая попытка. Все уроки доступны в произвольном порядке.

Для 1 класса предусмотрены крупные элементы и озвучка. По мере повышения класса вводятся условия, циклы, переменные, проверка источников и критическая оценка ИИ. Учитель может назначить конкретный урок устно; кабинет учителя не требуется.

## Границы покрытия

Темы сгруппированы в 69 микроуроков, а не в 119 академических часов. Знакомство с файлами, редакторами, Scratch, мультимедиа, презентациями и датчиками представлено объяснениями и упрощёнными упражнениями. Нет настоящей записи звука, видеомонтажа, полного редактора презентаций, исполнения Scratch или подключения физических роботов. Моделирование маршрута не является эмулятором аппаратных датчиков. Примеры ИИ заранее подготовлены, внешняя модель ребёнку не подключается.

Дальнейшая педагогическая верификация: сопоставить каждый микроурок с точными кодами целей, проверить возрастную сложность и казахский текст с преподавателем, расширить практические тренажёры по результатам экспертизы. Без исследования с учениками нельзя утверждать доказанное повышение успеваемости.
