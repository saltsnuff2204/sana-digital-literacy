# Бесплатная сборка iOS и установка через Windows

Проверено по документации 24 ноября 2026. Облачная сборка выполнена успешно. Установка на физический iPhone ещё НЕ выполнена. Это путь для личной демонстрации, а не публикации в App Store.

## Схема

Исходники Sana → GitHub Actions (macOS, Xcode, без подписи) → Sana-unsigned.ipa → AltStore Classic / AltServer на Windows → подпись бесплатным Apple Account → iPhone.

Apple Account не передаётся в GitHub и не нужен при сборке. Expo EAS и платное членство Apple Developer для этого пути не используются. Готовый IPA сам по себе не установится: AltStore должен подписать его для устройства.

## Стоимость и доступ

Стандартные GitHub-hosted runners в публичных репозиториях бесплатны. Исходники публичного репозитория видны всем — публиковать дипломный проект следует только осознанно. В приватном репозитории сборка расходует включённый лимит аккаунта: перед запуском проверь Billing и установи нулевой бюджет с остановкой при исчерпании лимита. Хранение артефактов имеет отдельный лимит; workflow сохраняет IPA только на один день. Скачай его сразу и удали ненужные артефакты. Публичный репозиторий не создавался автоматически.

## Сборка

1. Создай репозиторий GitHub. Загрузи содержимое папки `sana` в корень: `package.json` и `.github` должны быть в корне репозитория. GitHub Desktop на Windows позволяет это сделать без командной строки. `.gitignore` исключает локальную базу учеников, `.env`, node_modules и ключи; перед публикацией просмотри список файлов.
2. Обязательно загрузи `assets/audio` (138 файлов), `package-lock.json`, `plugins`, `scripts` и скрытую папку `.github`.
3. Открой **Actions → Build iOS IPA (unsigned) → Run workflow**. Workflow запускается только вручную. GitHub может потребовать включить Actions или подтвердить аккаунт.
4. При успешном завершении скачай артефакт **Sana-iOS-unsigned**. Распакуй внешний ZIP, внутри будет `Sana-unsigned.ipa` и SHA-256. Сам IPA распаковывать не нужно.
5. Если сборка завершится ошибкой, сохрани лог шага и артефакт `iOS-build-log`. При ошибках следующих сборок несовместимости Xcode/Pods нужно исправлять по этому логу.

Workflow собирает Release для настоящего iPhone, а не симулятора, проверяет встроенный JavaScript и 138 MP3. Первичный запуск аккаунта не обязателен: уроки доступны в пробном режиме. Для синхронизации укажи доступный HTTPS-сервер в расширенных настройках входа.

## Установка через Windows

1. Следуй официальной инструкции AltStore Classic для Windows: установи требуемые iTunes/iCloud и AltServer. Ссылки на установщики бери с официальной страницы, не с зеркал. Если iCloud уже установлен из Microsoft Store, используй указанную там альтернативную инструкцию.
2. Подключи разблокированный iPhone кабелем, нажми «Доверять этому компьютеру». Включи синхронизацию по Wi-Fi в iTunes.
3. В меню AltServer выбери **Install AltStore → свой iPhone**. Введи Apple Account непосредственно в приложение установки, не в чат и не в GitHub. Выполни запросы подтверждения Apple.
4. На iPhone доверься профилю в **Настройки → Основные → VPN и управление устройством**. На iOS 16+ включи **Конфиденциальность и безопасность → Режим разработчика**, перезагрузи телефон и подтверди включение.
5. Перенеси `Sana-unsigned.ipa` в приложение «Файлы» на iPhone (например, через iCloud Drive). В AltStore Classic открой **My Apps → +** и выбери IPA. Компьютер с AltServer должен быть доступен телефону.
6. Запусти Sana. Проверь урок, звук, тёмную тему; затем включи авиарежим и повтори запуск. Вход и синхронизацию проверяй отдельно с интернетом и доступным сервером.

## Ограничения

- Бесплатная подпись действует 7 дней. Обновляй её через **AltStore → My Apps → Refresh All** при доступном AltServer до истечения срока. Пересобирать неизменённый проект каждую неделю не требуется.
- Бесплатный аккаунт ограничен тремя активными sideload-приложениями; AltStore занимает один из слотов.
- После истечения подписи приложение перестаёт открываться до обновления. Не удаляй Sana ради обновления: удаление приложения может удалить локальный прогресс.
- Для iPad установка и подпись выполняются отдельно. Один аккаунт ученика объединяет прогресс через наш сервер, независимо от Apple Account.
- Совместимость с конкретной моделью и iOS определяется собранным приложением и ещё не проверена на устройстве пользователя.
